# 졸업네컷

> 졸업영상 만들기에 수고를 덜어줌

## 1. 프로젝트 소개
- 주 사용자: 교사와 학생
- 문제 영역: 생활교육·상담
- 결과물 형태: 웹앱
- 완성 상태: 바로 사용 가능

## 2. 해결하려는 문제
졸업영상 촬영 수고를 덜기위함.

## 3. 해결 방법
아이들이 졸업앨범 촬영날 기다리는 시간 동안 찍고 이걸 모아서 영상에 활용

## 4. 핵심 기능
- 인생네컷을 찍을 수 있고 찍는동안의 영상 타임랩스도 함께 저장된다.

## 5. 사용 흐름
1. 애들이 찍는다.
2. 교사는 영상과 사진을 모아 활용한다.

## 6. 검토 및 개선
- 검토 및 개선 내용을 입력해 주세요.

## 7. 성찰과 성장
- 사람이 확인한 일: 없음.
- 개인정보 처리: 개인정보를 처리함
- 배운 점: 좀더 복잡한 구조의 바이브 코딩과 배포, 푸시등 할 수 있게 된것.
- 다음 계획: 많은 사람들이 사용할 수 있는 좋은 프로그램 개발해보기
